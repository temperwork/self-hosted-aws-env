# Security policy

Please don't report security problems in a public GitHub issue.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/temperwork/self-hosted-aws-env/security/advisories/new) for this repository, or through your temperwork contact. Include what you found, how to reproduce it, and its impact. We'll acknowledge your report and keep you updated while we fix it.

Never include your external id, enrollment tokens, VPN profiles or AWS credentials in a report or an issue.
